CyberDoom Installer

Back up, install and restore Doom on a Makeblock CyberPi from the browser. Uses Web Serial: Chrome or Edge on a computer. Connect the CyberPi with USB first.

This browser can't talk to serial ports

Use Chrome or Edge on Windows, macOS, Linux or ChromeOS. Or flash with esptool as described in the README.

Step 1

Back up the CyberPi

Saves the whole 8 MB flash, including Makeblock's firmware, so the CyberPi can be put back exactly as it was. Takes about four minutes. Keep the file: it belongs to this CyberPi only.

Step 2

Install Doom

Looking for the latest firmware…

Use a firmware file instead
Any time

Restore a backup

Writes a backup made in step 1 back to the CyberPi. This replaces Doom and its saves.

Ready.

    
If connecting fails, unplug and replug the CyberPi and try again.
      Only one program can use the port at a time.
