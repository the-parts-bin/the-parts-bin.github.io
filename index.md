Welcome to The Parts Bin! I've been collecting boards and electronic components for many years now, and it's high time to put them to use *and* write about it!

Many things you'll see here have been developed with the help of coding agents, which help dramatically speeding up the transformation of ideas and weird designs into actual code. While I've been doing this kind of stuff for decades, this definitely improved the entertainment value of doing random hardware/software projects, and I really hope you'll find inspiraction here for your own - it was never cheaper or easier to get into this space than now.
